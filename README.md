# Proyecto D.O.M — Frontend 2.0

Proyecto de práctica sobre la manipulación del **Document Object Model (DOM)** utilizando HTML5, CSS3 y JavaScript vanilla.

---

## 🚀 Descripción

Este proyecto forma parte del módulo de desarrollo frontend. Su objetivo principal es poner en práctica conceptos clave de interacción con el navegador, selección de elementos, manejo de eventos y actualización dinámica de la interfaz de usuario mediante JavaScript.

---

## 🛠️ Tecnologías utilizadas

* **HTML5:** Estructura semántica de la página.
* **CSS3:** Estilos visuales y maquetación interactiva.
* **JavaScript (ES6+):** Lógica para manipulación del DOM y manejo de eventos.
